# Pathbridger extension icon

An ivory bridge connects the two sides of the workflow, with a gold wayfinding
diamond adding a restrained adventure motif. The forest green follows the
existing settings UI.

Generated using the built-in image generation tool. Master artwork lives at
`docs/pathbridger-icon.png`; browser PNGs live in `extension/icons/` at 16, 32,
48, and 128 pixels. Both extension and toolbar icons are set in the source
manifest and copied into Chrome and Firefox packages by the normal build.

## Generation prompt

Use case: logo-brand. Create one finished browser extension icon for Pathbridger,
a tool connecting Pathfinder character sheets to play-by-post forums. A very
simple bold ivory arched bridge inside a forest-green rounded square, with the
bridge's single large open arch and two solid piers unmistakable. A small warm
gold diamond centered above the bridge suggests a tabletop adventure wayfinding
marker. Flat crisp vector-like artwork, elegant geometric silhouette, restrained
fantasy feel, no ornament. Palette matches existing app: forest green #235c4a,
ivory #f2f3ed, warm muted gold. Square canvas, rounded green tile fills 94% of
canvas with genuinely transparent outer corners/background. Bridge fills most
of tile width with generous but minimal padding. Thick shapes readable at 16px.
No text, no letters, no numbers, no thin strokes, no shadows, no gradients, no
3D, no mockup, no multiple options. Deliver single production icon.

## Refinement prompt

Edit this Pathbridger icon. Preserve exactly the ivory bridge silhouette and gold
diamond placement and rounded square composition. Fix only the background: the
entire interior rounded square must be a completely solid opaque uniform flat
forest green #235c4a, including beneath the bridge arch and either side of the
gold diamond. Remove all dark holes, transparency holes, mottling, shadows,
gradients and texture within the green tile. Transparency is allowed ONLY outside
the rounded square. Ivory bridge and gold diamond should also be flat solid
colors. Crisp flat vector-like production browser extension icon. No other changes.

## Final refinement prompt

Produce this icon with NO TRANSPARENCY anywhere. Opaque RGB image. Solid forest
green #235c4a background edge to edge across the entire square canvas, no rounded
tile or outer margin. Keep the bold ivory bridge and gold diamond centered in the
same locations and same sizes. Replace ALL dark blotches with solid uniform
forest green. Completely flat solid fills, no shading or texture. Single browser
extension logo, no text.
