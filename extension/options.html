2. Review actions

Confirm every bonus and damage formula against your sheet. Set agile to true for agile attacks. Use map: [-3,-6] for a custom penalty, or null for standard MAP. Use mapIncreases: 0 for non-attack checks, or a positive integer for how many attacks an action contributes (default 1). Missing damage stays blank.

At the table

In a Paizo text box, choose Enable Pathbridger. Type /short and press Tab or Enter to complete a matching action. Arrow keys select; Escape dismisses. Each message is one turn. MAP comes from earlier labeled attack rolls before the cursor.

Deleting or inserting earlier attacks updates MAP for the next completion. Existing rolls retain their formulas. Recognized manual labels include Strike, Attack, Trip, Grapple, Shove, Disarm, Reposition, Escape, and Spell attack. Plain prose, damage rolls, and quoted rolls do not count. Special actions such as Double Slice need manual rolls.

Data stays in this Firefox profile. This prototype does not sync Google Drive or modify inventory.
